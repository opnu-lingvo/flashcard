## Передумови створення цього проєкту
В університеті нещодавно завершився курс підвищення кваліфікації, який пов'язаний зі створенням навчальної програми мікрокваліфікації. 

Було створено проєктну команду у складі:
- викладач з кафедри лінгводидактики, який має досвіт навчання іноземних студентів мовам;
-	викладач з кафедри психології та соціальної роботи, який має досвіт проведення психотерапевтичних занять з використанням метафоричних асоціативних карток та карток емоцій;
-	викладач з кафедри інформаційних систем, який має досвіт створення AR-карток - https://github.com/Information-System-ICS/ARFlashCard.
Саме вказаний досвіт викладачів визначив початок робіт з розробки
"Система інформаційної підтримки засвоєння іноземних мов: проєктування, психологія та технології з використанням паперових, цифрових та AR-флеш-карток"
